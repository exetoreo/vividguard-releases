# VividGuard downloads

Installers for **VividGuard**, the Windows anti-malware app by Vivid Software.

Download the latest `VividGuard-Setup-*.exe` from [Releases](../../releases/latest), run it, then enter the license key from your order on the **License** page.

- Windows 10 / 11 (64-bit). No admin rights needed: installs for your user account.
- Runs alongside Windows Security; it does not turn it off.
